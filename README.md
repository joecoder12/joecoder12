I like poking at systems until they tell me how they work, then figuring out how to lock the door behind me.

I'm a Computer Science (Cyber Security) student at Manipal Institute of Technology, Bengaluru. My interests sit at the intersection of network security, vulnerability assessment, security monitoring, and identity & access management.

### What I'm up to

- Built a Python vulnerability scanner on top of Nmap for host discovery, port scanning, and service detection
- Set up an intentionally vulnerable web app lab to hunt SQL Injection and XSS with Burp Suite
- Completed the Mastercard and Tata Cybersecurity Job Simulations (Forage), plus Cisco's Introduction to Cybersecurity
- Learning IAM & directory services — Active Directory, LDAP/LDAPS, Kerberos, service accounts
- Marketing Head at Apex Technical Club — ran promotions and comms for 5+ technical events
- Off the keyboard: college-level football player
